# Notification Sounds

Place notification sound files in this directory.

## Required Files

- `notification.mp3` - Subtle notification sound for pre-prayer warnings

## File Format

- Format: MP3
- Recommended: Short, subtle sound (1-2 seconds)
- Volume: Should be quieter than athan audio

## Usage

The notification sound plays:
- 10 minutes before each prayer (optional)
- During Suhoor warnings in Ramadan mode (15, 10, 5 minutes before Fajr)
