# Athan Audio Files

Place your athan MP3 files in this directory.

## Required Files

- `athan.mp3` - Main athan (Dhuhr, Asr, Maghrib, Isha)
- `fajir.mp3` - Fajr athan
- `dua.mp3` - Dua played after athan
- `chime.mp3` - Optional soft chime for Ramadan overlay (Maghrib/Taraweeh at-time)
- `makkah.mp3` - Legacy default (Makkah)
- `madinah.mp3` - Madinah athan
- `mishary.mp3` - Mishary Rashid Alafasy athan
- `abdulbasit.mp3` - Abdul Basit Abdul Samad athan

## File Format

- Format: MP3
- Recommended bitrate: 128-192 kbps
- Recommended sample rate: 44.1 kHz

## Where to Get Audio Files

You can find free athan audio files from:
- Islamic websites and apps
- YouTube (convert to MP3)
- Islamic audio libraries

**Note:** Ensure you have the rights to use any audio files you download.

## Custom Athan

You can use any MP3 file as a custom athan. Just name it appropriately and select it in the settings interface.
